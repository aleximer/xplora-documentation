Telavox (earlier eRate) provides mobile subscription APIs. There are three different types of API. Signup V1 (all the countries except Norway), Signup V2 (Norway only) and Billiant API V1.

## Billiant API

Billiant API is work in progress (as of 14.02.2024). Starting with Sweden, there will be **MANDATORY** migration from all eRate APIs to the new Billiant API.
